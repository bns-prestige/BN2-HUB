# BN2 HUB

Plateforme SaaS interne de BN2 Consulting pour gérer les entreprises clientes et leurs demandes informatiques.

## Vision

- BN2 HUB Admin : espace central de gestion des clients, contrats, demandes et interventions.
- Portail client : espace personnalisé pour chaque entreprise.
- Template maître : structure commune et composants réutilisables.
- Générateur assisté par IA : personnalisation contrôlée des portails à partir du template maître.

## Direction visuelle

Reprendre l'identité du site BN2 Consulting :
- Sora pour les titres.
- Manrope pour les textes et interfaces.
- Palette claire/sombre, bleu et violet en accents.
- Cartes arrondies, bordures fines, espaces généreux.
- Design responsive, minimaliste et accessible.

## Principes

- Une seule plateforme multi-entreprises.
- Isolation stricte des données de chaque client.
- Rôles et permissions par entreprise.
- L'IA configure le contenu et les modules autorisés ; elle ne génère pas librement le code de sécurité ou l'architecture.
- Les actions sensibles (notamment onboarding/offboarding) nécessitent une validation humaine.

## État

Initialisation du dépôt et préparation du cahier des charges. Aucun backend ni aucune fonctionnalité métier n'est encore déployé.
